# FastGPT 完整语音交互实现方案

## 🎯 目标

展示一个**完整的语音交互系统**：
```
用户说话 → ASR识别 → 知识库检索 → LLM生成 → TTS朗读（古文念对）
```

---

## 方案 A：FastGPT 工作流 + HTTP 节点集成外部服务（推荐）

### 架构
```
[用户语音输入]
    ↓ (前端处理或单独节点)
[ASR节点] - 调用腾讯云/阿里云 ASR API
    ↓
[知识库检索]
    ↓
[代码执行] - 判断相似度
    ↓
[条件分支]
    ├─ [拒答]
    └─ [LLM生成]
         ↓
[HTTP请求节点] - 调用古文TTS前端服务
    ↓
[HTTP请求节点] - 调用腾讯云TTS API
    ↓
[返回音频URL]
```

### 实现步骤

#### 1. 部署古文TTS前端服务

在本地运行：
```bash
cd E:\002_Personal_Works\projects\20260908-西安培训课\demo\fastgpt\tools

# 创建 Flask 服务
python guwen_tts_server.py
```

`guwen_tts_server.py`:
```python
from flask import Flask, request, jsonify
from guwen_tts_frontend import GuwenTTSFrontend

app = Flask(__name__)
frontend = GuwenTTSFrontend()

@app.route('/process', methods=['POST'])
def process():
    data = request.json
    text = data.get('text', '')
    
    result = frontend.process(text)
    
    return jsonify({
        'original': result['original'],
        'processed': result['final'],  # 处理后的文本
        'annotations': result['annotations']
    })

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```

#### 2. 在 FastGPT 工作流中添加 HTTP 请求节点

在 LLM 生成节点之后：

**HTTP 节点 1：古文文本处理**
```
URL: http://你的公网IP:5000/process
Method: POST
Body: {
  "text": "{{LLM生成.answer}}"
}
```

**HTTP 节点 2：调用 TTS**
```
URL: https://tts.tencentcloudapi.com/
Method: POST
Headers:
  Authorization: （腾讯云签名）
Body: {
  "Text": "{{HTTP节点1.processed}}",
  "SessionId": "{{$chatId}}",
  "ModelType": 1,
  "VoiceType": 1
}
```

## 方案 C：前端集成（最简单、演示效果好）

### 架构
```
[Web前端] - 自己写一个简单页面
    ├─ 语音输入（浏览器 Web Speech API）
    ├─ 调用 FastGPT API
    └─ TTS 输出（调用腾讯云或浏览器 TTS）
```

### 实现

创建 `demo.html`:
```html
<!DOCTYPE html>
<html>
<head>
    <title>古籍语音问答</title>
    <style>
        body { 
            font-family: Arial; 
            max-width: 800px; 
            margin: 50px auto; 
            padding: 20px;
        }
        #voiceBtn {
            background: #007bff;
            color: white;
            border: none;
            padding: 15px 30px;
            font-size: 18px;
            border-radius: 5px;
            cursor: pointer;
        }
        #voiceBtn:hover { background: #0056b3; }
        #voiceBtn.listening {
            background: #dc3545;
            animation: pulse 1s infinite;
        }
        @keyframes pulse {
            0%, 100% { transform: scale(1); }
            50% { transform: scale(1.05); }
        }
        #result {
            margin-top: 20px;
            padding: 15px;
            background: #f8f9fa;
            border-radius: 5px;
            min-height: 100px;
        }
    </style>
</head>
<body>
    <h1>🎙️ 古籍语音问答助手</h1>
    
    <button id="voiceBtn">按住说话</button>
    <div id="status">准备就绪</div>
    <div id="result"></div>
    
    <script>
        const FASTGPT_API = 'https://fastgpt.io/api/v1/chat/completions'; // 你的 FastGPT API
        const FASTGPT_KEY = '你的API密钥';
        
        const recognition = new (window.SpeechRecognition || window.webkitSpeechRecognition)();
        recognition.lang = 'zh-CN';
        
        const voiceBtn = document.getElementById('voiceBtn');
        const status = document.getElementById('status');
        const result = document.getElementById('result');
        
        // 按住说话
        voiceBtn.addEventListener('mousedown', () => {
            recognition.start();
            voiceBtn.classList.add('listening');
            voiceBtn.textContent = '🎤 正在听...';
            status.textContent = '请说话...';
        });
        
        voiceBtn.addEventListener('mouseup', () => {
            recognition.stop();
            voiceBtn.classList.remove('listening');
            voiceBtn.textContent = '按住说话';
        });
        
        // 识别结果
        recognition.onresult = async (event) => {
            const text = event.results[0][0].transcript;
            status.textContent = `识别到：${text}`;
            result.textContent = '正在思考...';
            
            // 调用 FastGPT
            const answer = await callFastGPT(text);
            result.textContent = answer;
            
            // 朗读答案（这里可以调用腾讯云TTS或古文处理服务）
            speak(answer);
        };
        
        async function callFastGPT(question) {
            try {
                const response = await fetch(FASTGPT_API, {
                    method: 'POST',
                    headers: {
                        'Content-Type': 'application/json',
                        'Authorization': `Bearer ${FASTGPT_KEY}`
                    },
                    body: JSON.stringify({
                        messages: [{role: 'user', content: question}]
                    })
                });
                const data = await response.json();
                return data.choices[0].message.content;
            } catch (e) {
                return '调用失败：' + e.message;
            }
        }
        
        function speak(text) {
            // 这里可以：
            // 1. 先调用你的古文TTS前端处理 (http://localhost:5000/process)
            // 2. 再调用腾讯云TTS
            // 3. 或者简单用浏览器TTS演示
            const utterance = new SpeechSynthesisUtterance(text);
            utterance.lang = 'zh-CN';
            window.speechSynthesis.speak(utterance);
        }
    </script>
</body>
</html>
```
