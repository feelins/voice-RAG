## 🎯 基础概念

### Q1: 什么是讯飞星辰Agent？

**A**: 讯飞星辰Agent是讯飞推出的一站式AI智能体开发平台。

**特点**：
- 🎨 可视化工作流编排（拖拽式开发）
- 🤖 内置虚拟数字人形象
- 📚 支持知识库上传和管理
- 🔊 集成ASR、TTS、LLM能力
- ☁️ 云端托管，无需部署

**适用场景**：
- 快速验证AI应用想法
- 无技术团队的企业
- 需要虚拟数字人的场景

---

### Q2: 什么是Flask自研方案？

**A**: 基于Python Flask框架，自主开发的AI问答系统。

**特点**：
- 💻 代码完全开源可控
- 🔧 高度定制化
- 🏠 可私有化部署
- 📊 技术栈灵活选择
- 💰 按量付费，成本透明

**适用场景**：
- 学习AI开发技术
- 企业内部系统
- 需要深度定制

---

### Q3: 两者本质区别是什么？

**A**: 

| 维度 | 星辰Agent | Flask自研 |
|------|----------|----------|
| **开发方式** | 配置为主（低代码） | 编程为主（写代码） |
| **技术栈** | 平台提供（黑盒） | 自主选择（透明） |
| **部署方式** | 云端托管 | 自主部署 |
| **比喻** | 组装电脑（买配件） | DIY电脑（从零组装） |

**简单理解**：
- 星辰Agent = **iPhone**（封闭生态，易用但不可深度定制）
- Flask自研 = **Android**（开放生态，灵活但需要技术）

### Q12: Flask方案有哪些成本？

**A**: 主要是**API调用 + 服务器**。

**详细成本清单（以通义千问为例）**：

```
API调用费用：
├─ ASR：¥0.02 / 分钟
├─ TTS：¥0.03 / 千字符
└─ LLM：¥0.5 / 百万tokens

示例：1000次对话/月
├─ ASR：1000次 × 1分钟 × ¥0.02 = ¥20
├─ TTS：1000次 × 100字 × ¥0.03/千字 = ¥3
├─ LLM：1000次 × 500tokens × ¥0.5/百万 = ¥0.25
└─ 小计：¥23.25

服务器费用：
├─ 云服务器（2核4G）：¥100/月
├─ 数据库（小型）：¥50/月
├─ 带宽/CDN：¥50/月
└─ 小计：¥200/月

总成本：约¥230/月（1000次对话）
```

**省钱技巧**：
1. 对比不同厂商API价格（讯飞、百度、阿里）
2. 用缓存减少重复调用
3. 选择性价比高的服务器
4. 初期用本地开发机，省服务器费

## 🔒 安全与隐私

### Q13: 数据安全性如何？

**A**: Flask自研**更安全**。

**星辰Agent**：
- ⚠️ 数据存储在讯飞云服务器
- ⚠️ 知识库内容上传到平台
- ⚠️ 对话记录可能被用于模型训练（看协议）
- ⚠️ 无法完全控制数据流向

**Flask自研**：
- ✅ 数据存储在自己的服务器
- ✅ 可私有化部署（内网运行）
- ✅ 完全掌控数据流向
- ✅ 符合企业安全规范

**建议**：
- 涉及敏感数据（医疗、金融、法律）→ 必须自研
- 公开知识（百科、常识）→ 平台方案可接受
- 企业内部文档 → 必须自研并私有化

## 🛠️ 技术问题

### Q15: 能在星辰Agent中使用自己训练的TTS模型吗？

**A**: ❌ **不能**，这是核心限制。

**星辰Agent只能用**：
- 平台提供的官方音色
- 基础音色库
- 自己录制的一句话音色（有限功能）

**Flask自研可以**：
```python
# app.py 中可以灵活切换

def synthesize_speech(text, voice_type):
    if voice_type == 'custom_scholar':
        # 使用自训练模型
        from my_tts_model import generate
        audio = generate(text, model_path='./models/scholar.pth')
    else:
        # 使用API
        synthesizer = SpeechSynthesizer(...)
        audio = synthesizer.call(text)
    
    return audio
```

**实际案例**：
- 博物馆需要特定讲解员音色 → 必须自研
- 企业需要品牌专属语音IP → 必须自研
- 标准音色够用 → 平台方案可接受

### Q17: 识别错误怎么办？

**A**: 两个方案的处理能力**完全不同**。

**场景**："学而时习之"被识别成"学二十一"

**星辰Agent能做的**：
1. ⚠️ 换一个ASR模型试试
2. ⚠️ 在提示词中加"纠错"逻辑
3. ❌ 无法调整识别参数
4. ❌ 无法音频预处理

**Flask自研能做的**：
```python
# 方案1：调整识别参数
recognizer = Recognition(
    model='paraformer-v2',  # 更换模型
    format='wav',
    sample_rate=16000,  # 提高采样率
    enable_inverse_text_normalization=True  # 开启标点
)

# 方案2：音频预处理
import librosa
audio, sr = librosa.load(audio_file, sr=16000)
audio = librosa.effects.trim(audio)[0]  # 去除空白
audio = nr.reduce_noise(audio, sr)  # 降噪

# 方案3：结果后处理
result = asr_call(audio)
# 古籍专用词典纠错
result = result.replace("学二十一", "学而时习之")
result = result.replace("孔子子", "孔子")

# 方案4：多模型投票
results = []
for model in ['qwen', 'baidu', 'iflytek']:
    results.append(call_asr(audio, model))
# 选择最一致的结果
final_result = vote(results)
```

**结论**：自研方案的调试能力**远超**平台方案。

**A**: ⚠️ **分阶段选择**。

**第一阶段：MVP验证（1-3个月）**
- 推荐：**星辰Agent** ✅
- 理由：快速上线，节省开发成本
- 目标：验证商业模式

**第二阶段：规模化（3-12个月）**
- 评估：用户量和定制需求
- 转折点：月调用量 > 5000次
- 决策：
  - 用户少、需求简单 → 继续用星辰Agent
  - 用户多、需求复杂 → 切换到Flask自研

**第三阶段：产品化（1年+）**
- 推荐：**Flask自研** ✅
- 理由：
  - 长期成本更低
  - 技术积累在公司内部
  - 完全掌控产品演进

**关键提示**：
- 不要一开始就追求"完美技术方案"
- 先验证商业价值，再优化技术架构
- 留好技术重构的预算和时间
