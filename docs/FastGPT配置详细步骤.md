## 步骤 1：在 FastGPT 中添加模型（10分钟）

### 1.1 进入模型管理

1. 登录 FastGPT：https://fastgpt.io/
2. 点击右上角头像 → **系统设置**
3. 左侧菜单找到 **模型提供商**

### 1.2 添加 SiliconFlow

点击 **添加模型提供商**，填写以下信息：

```
名称：SiliconFlow
基础地址：https://api.siliconflow.cn/v1
API Key：（粘贴你的 SiliconFlow API Key）
```

点击 **测试连接** → 成功后点击 **保存**

### 1.3 添加对话模型

在刚添加的 SiliconFlow 提供商下，点击 **添加模型**：

```
模型名称：Qwen2.5-7B
模型标识：Qwen/Qwen2.5-7B-Instruct
模型类型：对话模型（Chat）
```

保存后，模型就可以使用了。

### 1.4 添加 Embedding 模型（用于向量检索）

再次点击 **添加模型**：

```
模型名称：BGE-M3
模型标识：BAAI/bge-m3
模型类型：Embedding（向量）
```

保存。

## 步骤 2：创建知识库（15分钟）

### 2.1 创建知识库

1. 点击左侧 **知识库**
2. 点击 **创建知识库**
3. 填写信息：
   ```
   名称：古籍问答知识库
   描述：包含论语、史记、资治通鉴等古籍选段
   ```
4. 点击 **确认**

### 2.2 上传文档

1. 进入刚创建的知识库
2. 点击 **上传文档**
3. 选择文件：`E:\002_Personal_Works\projects\20260908-西安培训课\demo\fastgpt\data\corpus\古籍语料合集.txt`
4. 配置参数：
   ```
   分段模式：通用文本
   分段长度：256
   分段重叠：50
   ```
5. 点击 **开始处理**

等待 2-3 分钟，文档会自动切分并向量化。

### 2.3 测试召回

1. 点击知识库的 **搜索测试**
2. 输入测试问题：

**测试1**：`学而时习之`
- 预期：应该召回《论语·学而》相关内容，分数 > 0.5

**测试2**：`红楼梦第五回`
- 预期：分数应该很低（< 0.3），因为语料中没有

如果两个测试都符合预期，说明知识库配置成功！

## 步骤 3：创建应用（搭建工作流）（20分钟）

### 3.1 创建应用

1. 点击左侧 **应用**
2. 点击 **创建应用**
3. 选择 **工作流编排**（不是简单问答）
4. 填写：
   ```
   应用名称：古籍问答助手
   应用描述：基于古籍知识库的智能问答
   ```
5. 点击 **确认**

### 3.2 搭建工作流（6个节点）

进入应用后，点击 **工作流** 标签页，开始拖拽节点：

#### 节点 1：用户输入（默认已有）
- 不需要改动

#### 节点 2：知识库检索

1. 从左侧拖拽 **知识库搜索** 节点到画布
2. 配置：
   ```
   知识库：选择"古籍问答知识库"
   检索数量（TopK）：3
   最低相似度：0（不在这里过滤）
   ```
3. 连接：**用户输入** → **知识库检索**

#### 节点 3：代码执行（判断相似度）

1. 拖拽 **代码执行** 节点
2. 输入代码：
   ```javascript
   function main({retrieval_results}) {
     const THRESHOLD = 0.5;
     
     if (!retrieval_results || retrieval_results.length === 0) {
       return {
         should_answer: false,
         reason: "未检索到相关内容"
       };
     }
     
     const max_score = Math.max(...retrieval_results.map(r => r.score));
     
     if (max_score < THRESHOLD) {
       return {
         should_answer: false,
         reason: `相似度 ${max_score.toFixed(2)} 低于阈值 ${THRESHOLD}`
       };
     }
     
     return {
       should_answer: true,
       reason: `相似度 ${max_score.toFixed(2)} 符合要求`
     };
   }
   ```
3. 输入变量：
   - 变量名：`retrieval_results`
   - 来源：选择 **知识库检索.引用内容**
4. 连接：**知识库检索** → **代码执行**

#### 节点 4：条件分支

1. 拖拽 **条件分支** 节点
2. 配置条件：
   ```
   条件：{{代码执行.should_answer}} == true
   ```
3. 连接：**代码执行** → **条件分支**

#### 节点 5A：拒答（条件不成立）

1. 拖拽 **指定回复** 节点
2. 配置：
   ```
   回复内容：
   藏书中未见相关记载。
   
   判断原因：{{代码执行.reason}}
   ```
3. 连接：**条件分支（不成立）** → **指定回复** → **结束**

#### 节点 5B：AI 对话（条件成立）

1. 拖拽 **AI 对话** 节点
2. 配置：
   ```
   模型：选择 Qwen2.5-7B
   温度：0.3
   
   系统提示词：
   你是古籍问答助手。严格遵守以下规则：
   1. 只根据检索内容回答，不得编造
   2. 回答时必须引用原文
   3. 在回答末尾标注出处：【出处：书名·篇名】
   
   用户提问：{{用户输入.question}}
   
   检索到的内容：
   {{知识库检索.引用内容}}
   
   请根据上述内容回答。
   ```
3. 连接：**条件分支（成立）** → **AI 对话** → **结束**

### 3.3 保存并发布

1. 点击右上角 **保存**
2. 点击 **发布**

## 步骤 4：测试应用（10分钟）

### 4.1 进入调试模式

点击右上角 **调试** 按钮

### 4.2 测试 5 个问题

**测试 1：正常问答**
```
输入：学而时习之什么意思？
预期：✅ 应该回答并引用《论语》原文
```

**测试 2：拒答**
```
输入：红楼梦第五回讲什么？
预期：✅ 返回"藏书中未见相关记载"
```

**测试 3：专有名词**
```
输入：孔子的弟子有谁？
预期：✅ 准确识别人名并回答
```

**测试 4：多轮对话**
```
第一轮：孔子说学而时习之是什么意思？
第二轮：那有朋自远方来呢？
预期：✅ 第二轮能联系上文
```

**测试 5：边缘 case**
```
输入：论语讲的是什么？
预期：✅ 应该基于检索到的内容概括回答
```

### 4.3 验证成功标准

- ✅ 正例能回答，引用准确
- ✅ 负例能拒答
- ✅ 出处标注正确

## 💡 常见问题

### Q1：模型测试连接失败
- 检查 API Key 是否正确
- 检查网络连接
- 确认 SiliconFlow 余额充足

### Q2：知识库召回不准确
- 调整分段长度（试试 512）
- 降低相似度阈值（试试 0.4）
- 检查文档内容是否正确上传

### Q3：工作流执行出错
- 检查每个节点的连线
- 查看调试日志
- 确认变量名称匹配
