## 第三部分：核心模块详解（20分钟）

### 幻灯片 7：模块一 - ASR（让系统听懂）
**技术原理**：
- 音频采集 → 降噪 → 特征提取 → 模型识别 → 文字输出

**代码示例**（简化）：
```python
def recognize_speech(audio_file):
    recognizer = Recognition(model='paraformer-v2')
    result = recognizer.call(audio_file)
    return result.output.text
```

**关键参数**：
- 采样率：16000 Hz（标准）
- 格式：WAV（无损）
- 声道：单声道

### 幻灯片 8：ASR 效果对比
| 场景 | 识别准确率 | 典型问题 |
|------|-----------|---------|
| 安静环境 + 标准普通话 | 95%+ | - |
| 嘈杂环境 | 70-80% | 需要降噪预处理 |
| 方言（粤语） | 85-90% | 需要选择对应模型 |

### 幻灯片 9：模块二 - 知识库（让系统思考）

### 幻灯片 11：模块三 - TTS（让系统开口）
**技术原理**：
- 文字 → 音素转换 → 韵律预测 → 声学模型 → 音频波形

**代码示例**：
```python
def synthesize_speech(text, voice='longxiaochun'):
    synthesizer = SpeechSynthesizer(voice=voice)
    audio_data = synthesizer.call(text)
    return audio_data
```

**多音色支持**：
- 普通话：男声/女声
- 粤语：优雅/知性/欢脱

### 幻灯片 12：TTS 进阶 - 定制化语音
**为什么需要定制？**
- 场景匹配：古籍学者的语气、语速
- 品牌形象：独特的声音 IP

**实现路径**：
1. **录制音频**：10-30 分钟高质量录音
2. **训练模型**：GPT-SoVITS / VITS（数小时）
3. **接入系统**：替换 API 调用为本地推理

```python
@app.route('/voice_ask', methods=['POST'])
def voice_ask():
    audio_file = request.files['audio']
    
    # 1. ASR 识别
    text = recognize_speech(audio_file)
    
    # 2. 知识库查询
    answer = find_answer(text)
    
    # 3. TTS 合成
    audio = synthesize_speech(answer)
    
    return jsonify({'text': text, 'answer': answer, 'audio': audio})
```
