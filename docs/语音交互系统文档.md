# 古籍问答语音交互系统文档

## 📋 系统概述

本系统是一个基于阿里云 DashScope 的古籍问答语音交互系统，支持：
- 语音识别（Speech-to-Text）
- 智能问答（基于知识库）
- 语音合成（Text-to-Speech）
- 多语言/方言支持（普通话、粤语）

---

## 🎙️ 语音识别（ASR）

### 使用的 API
- **模型**：`paraformer-realtime-v2`
- **音频格式**：WAV，16kHz，单声道，16-bit PCM
- **识别语言**：中文普通话

### 工作流程
1. 浏览器录制音频（WebM 格式）
2. 前端使用 Web Audio API 转换为 16kHz 单声道 WAV
3. 上传到后端
4. 调用阿里云语音识别 API
5. 返回识别的文本

### 代码实现
```python
from dashscope.audio.asr import Recognition

recognizer = Recognition(
    model='paraformer-realtime-v2',
    format='wav',
    sample_rate=16000,
    callback=None
)

result = recognizer.call(audio_file_path)
```

## 🗣️ 语音合成（TTS）

### 支持的模型和语音

#### CosyVoice-v1（普通话）
- **longxiaochun**：普通话女声，知性积极
- **longyuan**：普通话男声，温暖治愈

#### CosyVoice-v3-flash（粤语）
- **longjiaxin_v3**：粤语女声，优雅
- **longjiayi_v3**：粤语女声，知性
- **longanyue_v3**：粤语男声，欢脱

### 语音选择配置

```python
VOICE_OPTIONS = {
    'mandarin_female': {
        'name': '普通话-女声',
        'voice': 'longxiaochun',
        'model': 'cosyvoice-v1'
    },
    'mandarin_male': {
        'name': '普通话-男声',
        'voice': 'longyuan',
        'model': 'cosyvoice-v1'
    },
    'cantonese_female': {
        'name': '粤语-女声（优雅）',
        'voice': 'longjiaxin_v3',
        'model': 'cosyvoice-v3-flash'
    },
    'cantonese_female2': {
        'name': '粤语-女声（知性）',
        'voice': 'longjiayi_v3',
        'model': 'cosyvoice-v3-flash'
    },
    'cantonese_male': {
        'name': '粤语-男声（欢脱）',
        'voice': 'longanyue_v3',
        'model': 'cosyvoice-v3-flash'
    }
}
```

### 工作流程
1. 用户选择语音类型（前端下拉菜单）
2. 语音识别后得到问题文本
3. 查询知识库得到答案文本
4. 根据选择的语音类型调用对应的 TTS API
5. 生成 MP3 音频文件
6. 返回给前端播放

### 代码实现
```python
from dashscope.audio.tts_v2 import SpeechSynthesizer

def synthesize_speech(text, output_filename, voice_type='mandarin_female'):
    voice_config = VOICE_OPTIONS.get(voice_type)
    
    synthesizer = SpeechSynthesizer(
        model=voice_config['model'],
        voice=voice_config['voice']
    )
    
    audio_data = synthesizer.call(text)
    
    # 保存音频
    output_path = os.path.join('static', 'audio', output_filename)
    with open(output_path, 'wb') as f:
        f.write(audio_data)
    
    return output_filename
```

## 🌐 前端实现

### 录音功能
使用 Web Audio API 实现：
1. `MediaRecorder` 录制音频（WebM/Opus）
2. `AudioContext` 解码音频
3. `OfflineAudioContext` 重采样到 16kHz
4. 编码为标准 WAV 格式
5. 上传到后端

### 语音选择器
```html
<select id="voiceSelect">
    <option value="mandarin_female">普通话-女声</option>
    <option value="mandarin_male">普通话-男声</option>
```

### 请求流程
```javascript
const formData = new FormData();
formData.append('audio', audioBlob, 'recording.wav');
formData.append('voice_type', voiceType);

const response = await fetch('/voice_ask', {
    method: 'POST',
```

## 📚 知识库问答

### 当前知识库
基于《论语》、《诗经》等古籍的问答对：
- 学而时习之是什么意思？
- 有朋自远方来是什么意思？
- 孔子的主要思想是什么？
- 诗经中有哪些著名篇目？
- 等等...

### 匹配逻辑
当前使用**精确匹配**和**部分匹配**：
```python
def find_answer(question):
    question = question.strip().replace('？', '').replace('?', '')
    
    # 精确匹配
    if question in QA_DATABASE:
        return {'answer': QA_DATABASE[question]}
    
    # 部分匹配
    for key in QA_DATABASE.keys():
        if question in key or key in question:
            return {'answer': QA_DATABASE[key]}
    
    # 未找到
    return {'answer': '抱歉，我暂时无法回答这个问题。您可以询问关于《论语》、孔子、《诗经》等古籍的问题。'}
```

## 🎯 关键特性

### 1. 语音识别准确性
- 使用阿里云 Paraformer 实时识别模型
- 支持中文普通话
- 可能存在同音字错误（如"时习"识别为"实习"）

### 2. 语音合成自然度
- CosyVoice 系列模型，高自然度
- 支持情感表达
- 粤语发音标准

### 3. 多语言支持
- **提问**：仅支持普通话识别
- **回答**：支持普通话和粤语朗读
- 语音选择仅影响回答语言，不影响识别语言

### 4. 音频格式处理
- 前端自动将浏览器录音转为 16kHz WAV
- 后端生成 MP3 格式音频
- 自动清理临时文件

## 🔍 已知问题和限制

### 1. 同音字识别错误
**问题**：语音识别可能将"时习"识别为"实习"

**解决方案**：
- 扩展知识库，添加常见同音字变体
- 使用模糊匹配
- 接入 LLM 进行语义理解

### 2. 知识库覆盖有限
**问题**：仅支持预设的问题

**解决方案**：
- 扩充知识库
- 接入 FastGPT 或 LLM 进行动态问答

### 3. 语音识别仅支持普通话
**问题**：无法用粤语提问

**解决方案**：
- 需要使用支持粤语识别的 ASR 模型
- 或在前端添加语言选择（识别语言 + 合成语言）

## 📊 性能指标

### 语音识别
- **延迟**：~1-3 秒
- **准确率**：普通话环境下 >90%

### 语音合成
- **延迟**：~2-4 秒（取决于文本长度）
- **音频大小**：约 30-100 KB（10-30 秒音频）

### 端到端延迟
- **总延迟**：~5-10 秒（从录音结束到播放回答）

## 🔐 安全注意事项

1. **API Key 保护**：不要将 `qwen.key` 提交到版本控制
2. **音频临时文件**：定期清理 `temp_recordings/` 和 `static/audio/`
3. **CORS 设置**：生产环境需要配置正确的 CORS 策略
4. **文件大小限制**：录音文件限制在合理范围（如 10MB）
