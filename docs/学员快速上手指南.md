### 任务 4：对比知识库方案（10分钟）
**目标**：理解硬编码 vs LLM 的差异


2. **观察对比**：

3. **分析差异**：

## 🐛 常见问题

### Q1: 启动失败，提示找不到 Key
**A**: 在项目根目录创建 `qwen.key` 文件，粘贴您的 API Key

### Q2: 安装依赖失败
**A**: 
```bash
# 尝试使用国内镜像
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

### Q3: 语音识别失败
**A**: 
- 检查麦克风权限（浏览器需要允许录音）
- 确认浏览器支持（推荐 Chrome）
- 录音时保持安静环境

### Q4: 没有声音
**A**: 
- 检查系统音量
- 点击界面上的播放按钮手动播放
- 检查浏览器是否允许自动播放

### Q5: API 调用失败
**A**: 
- 检查 Key 是否正确（没有多余空格）
- 检查网络连接
- 查看控制台错误信息

### Q6: 识别出的文字不对
**A**: 
- 说话清晰一些
- 靠近麦克风
- 避免方言（除非选择对应模型）
