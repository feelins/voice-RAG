# 古籍问答语音交互系统 - 课堂演示 Prompt

## 🎯 项目目标

构建一个基于阿里云 DashScope 的古籍问答语音交互系统，实现：
- 语音识别（ASR）
- 智能问答（知识库 + LLM）
- 语音合成（TTS）
- 多语言支持（普通话、粤语）

---

## 📝 课堂演示步骤

### 第一阶段：基础语音交互（30分钟）

#### 1. 创建项目结构
```
请帮我创建一个古籍问答语音交互系统的 Flask 项目，包含：
- Flask 后端框架
- 前端页面，包含学者形象、语音输入按钮、文字输入框
- 支持阿里云语音识别和合成
```

#### 2. 实现语音识别
```
请实现阿里云语音识别功能：
- 使用 paraformer-realtime-v2 模型
- 支持 16kHz WAV 格式音频
- 前端录音并转换为标准 WAV 格式
```

#### 3. 实现语音合成
```
请实现阿里云语音合成功能：
- 使用 CosyVoice 模型
- 支持普通话女声（longxiaochun）
- 生成 MP3 音频并播放
```

#### 4. 添加知识库
```
请添加一个古籍知识库，包含《论语》的常见问答：
- 学而时习之是什么意思
- 有朋自远方来是什么意思
- 三人行必有我师焉是什么意思
等等
```

### 第三阶段：智能问答优化（30分钟）

#### 7. 同音字问题演示
```
演示场景：
用户说"学而实习之是什么意思"（"时"被识别为"实"）
系统无法匹配，返回"无法回答"

请分析这个问题并提出解决方案。
```

#### 8. 实现 LLM + 知识库混合方案
```
请实现混合问答方案：
1. 先尝试知识库精确匹配
2. 再尝试知识库模糊匹配
3. 如果都没匹配到，使用 LLM 理解问题意图
4. LLM 从知识库中找到最相关的答案
5. 如果知识库中确实没有，返回友好提示

使用千问模型理解问题。
```

#### 9. 测试优化效果
```
测试场景：
1. "学而实习之是什么意思"（同音字）→ 应该正确回答
2. "学习并时常温习是什么意思"（近义词）→ 应该正确回答
3. "孔子说的学习的句子"（模糊描述）→ 应该找到相关内容
4. "红楼梦第五回讲什么"（超出知识库）→ 友好提示
```

## 🔧 常用调试 Prompt

### 音频格式问题
```
我的录音文件无法识别，显示格式错误。请检查：
1. 音频格式是否为 WAV
2. 采样率是否为 16kHz
3. 声道数是否为单声道
4. 编码是否为 16-bit PCM
并提供前端转换代码。
```

### 语音识别不准确
```
语音识别经常出现同音字错误，比如"时习"识别为"实习"。
请分析原因并提供优化方案：
1. 使用更高级的识别模型
2. 添加领域词汇表
3. 后处理纠错
4. 使用 LLM 理解意图
```

### 知识库匹配失败
```
知识库中明明有答案，但系统说"无法回答"。
可能的原因：
1. 问题表述不完全一致
2. 标点符号影响匹配
3. 多余的语气词
请提供更智能的匹配方案。
```

### 语音合成速度慢
```
语音合成需要等待很久才播放。请优化：
1. 检查网络延迟
2. 预生成常见回答的音频
3. 使用流式合成
4. 添加加载动画提升体验
```


在 `qwen.key` 文件中填入你的阿里云 API Key

## 📞 常见问题

**Q: 麦克风无法访问？**
A: 检查浏览器权限设置，HTTPS 环境下才能访问麦克风。

**Q: API 调用失败？**
A: 检查 API Key 是否正确，账户余额是否充足。

**Q: 语音识别不准确？**
A: 确保环境安静，说话清晰，使用高质量麦克风。

**Q: 粤语合成效果不好？**
A: 确保使用 cosyvoice-v3-flash 模型，使用正确的 voice ID。

**Q: LLM 回答不准确？**
A: 优化 Prompt，增加示例，调整知识库内容。
