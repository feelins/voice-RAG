### 3.1 工作流界面介绍

```
┌─────────────────────────────────────┐
│  工作流名称 [✏️] [历史版本] [对比测试]│
├─────────────────────────────────────┤

└─────────────────────────────────────┘
```

### 3.2 默认节点

工作流会自动创建两个节点：

**开始节点（Start）**：
- 位置：画布左侧
- 作用：接收用户输入
- 默认参数：`AGENT_USER_INPUT`

**结束节点（End）**：
- 位置：画布右侧
- 作用：输出最终结果
- 可配置：输出格式、流式输出

---

### 3.3 添加节点

#### 方式1：从节点列表拖拽

```
步骤：
1. 在左侧【节点列表】找到需要的节点
2. 鼠标拖拽到画布中央
3. 释放鼠标，节点创建成功
```

#### 方式2：点击节点后的"+"号

```
步骤：
1. 点击节点右侧的 [+] 按钮
2. 在弹出的菜单中选择节点类型
3. 节点自动添加并连线
```

---

### 3.4 节点连线

```

3. 拖到目标节点的左侧 ○ 圆点
```

**删除连线**：

#### 4.1.4 代码节点

**使用场景**：
- 数据处理（格式转换、清洗）
- 业务逻辑（计算、判断）
- 结果后处理（拼接、过滤）

**添加步骤**：
```
1. 拖拽【代码】节点到画布
2. 连接到上游节点
3. 配置代码逻辑
```

**配置面板**：

**① 配置输入**：
```
示例：
├─ input1 (String) - 引用大模型输出
└─ input2 (Array) - 引用知识库结果
```

**② 编写代码**：
```python
# -*- coding: utf-8 -*-
import json

def main(input1, input2):
    """
    主函数：处理输入参数，返回处理结果
    
    参数：
    - input1: 大模型的输出
    - input2: 知识库的检索结果
    
    返回：
    - result: 拼接后的答案
    """
    
    # 处理知识库结果
    kb_content = ""
    if input2 and len(input2) > 0:
        # 提取前3条结果
        for item in input2[:3]:
            kb_content += item.get('content', '') + "\n"
    
    # 拼接答案
    if kb_content:
        result = f"根据古籍记载：\n{kb_content}\n\n{input1}"
    else:
        result = input1
    
    # 返回结果（必须是字典格式）
    return {
        "result": result
    }
```

**③ 配置输出**：
```
result (String) - 与代码return的字段对应
```

**④ 调试代码**：
```
1. 点击【试运行】
2. 填写测试数据
3. 点击【运行】
4. 查看输出结果
```

### 5.3 错误排查

**常见错误**：

**错误1：参数引用错误**
```
症状：节点报错"找不到参数"
原因：引用的上游节点输出不存在
解决：检查参数名是否正确，连线是否正确
```

**错误2：数据类型不匹配**
```
症状：节点报错"类型错误"
原因：String传给了Number类型的参数
解决：使用代码节点转换类型
```

**错误3：超时**
```
症状：节点执行超时
原因：API调用时间过长
解决：增加超时时间，或优化逻辑
```

## 7. 完整案例：古籍问答助手

### 7.1 需求分析

**功能需求**：
```
用户输入：关于古籍的问题
系统处理：
├─ 识别用户意图
├─ 查询知识库
├─ 生成答案
└─ 语音播报

输出：文字答案 + 语音
```

---

### 7.2 节点编排流程

```
工作流结构：

开始节点
   │
   ├─→ 决策节点（意图识别）
   │     │
   │     ├─→ [古籍问答] → 知识库节点
   │     │                    │
   │     │                    ├─→ 大模型节点（整合答案）
   │     │                    │        │
   │     │                    │        └─→ 结束节点
   │     │
   │     ├─→ [闲聊] → 大模型节点 → 结束节点
   │     │
   │     └─→ [默认] → 兜底回复 → 结束节点
```

---

### 7.3 详细配置步骤

#### 步骤1：创建工作流
```
1. 点击【创建应用】→【工作流创建】
2. 选择【自定义创建】
3. 填写基本信息：
   ├─ 名称：古籍语音问答助手
   ├─ 描述：基于知识库的古籍问答系统
   └─ 分类：学习
```

#### 步骤2：配置开始节点
```
默认即可，使用 AGENT_USER_INPUT 接收用户输入
```

#### 步骤3：添加决策节点
```
1. 拖拽【决策节点】到画布
2. 连接：开始节点 → 决策节点
3. 配置：
   ├─ 选择模型：Qwen-Turbo
   ├─ 输入：引用开始节点的 AGENT_USER_INPUT
   ├─ 意图1：
   │   ├─ 名称：古籍问答
   │   ├─ 描述：用户询问关于中国古籍的问题
   │   └─ 示例：学而时习之是什么意思、孔子有哪些弟子
   └─ 意图2：
       ├─ 名称：闲聊
       └─ 描述：日常闲聊或寒暄
```

#### 步骤4：添加知识库节点（古籍问答分支）
```
1. 拖拽【知识库】节点
2. 连接：决策节点[古籍问答] → 知识库节点
3. 配置：
   ├─ 添加知识库：论语知识库
   ├─ Top K：3
   ├─ Score阈值：0.7
   └─ Query：引用开始节点的 AGENT_USER_INPUT
```

#### 步骤5：添加大模型节点（整合答案）
```
1. 拖拽【大模型】节点
2. 连接：知识库节点 → 大模型节点
3. 配置：
   ├─ 模型：Spark X1
   ├─ 输入参数：
   │   ├─ question：引用开始节点的 AGENT_USER_INPUT
   │   └─ kb_result：引用知识库节点的 result
   ├─ 系统提示词：
   │   你是一位古籍学者，擅长回答关于中国古代典籍的问题。
   │   
   │   回答要求：
   │   1. 基于提供的知识库内容回答
   │   2. 语言文雅、通俗易懂
   │   3. 控制在200字以内
   │   4. 如知识库没有相关内容，礼貌说明
   │
   └─ 用户提示词：
       用户问题：{{question}}
       
       知识库内容：
       {{kb_result}}
       
       请基于以上知识库内容，回答用户的问题。
```

#### 步骤6：连接结束节点（古籍问答分支）
```
1. 连接：大模型节点 → 结束节点
2. 配置结束节点：
   ├─ 回答模式：返回参数
   ├─ 输出：
   │   └─ answer (String)：引用大模型节点的 Output
   └─ 回答内容：{{answer}}
```

#### 步骤7：处理其他分支

**闲聊分支**：
```
1. 拖拽【大模型】节点
2. 连接：决策节点[闲聊] → 大模型节点
3. 配置：
   ├─ 模型：Qwen-Turbo
   ├─ 系统提示词：你是一个友好的助手，擅长闲聊
   └─ 用户提示词：{{AGENT_USER_INPUT}}
4. 连接到结束节点
```

**默认分支**：
```
1. 拖拽【大模型】节点
2. 连接：决策节点[默认] → 大模型节点
3. 配置：
   ├─ 系统提示词：
   │   礼貌引导用户询问古籍相关问题
   └─ 用户提示词：
       用户说：{{AGENT_USER_INPUT}}
       
       请礼貌地引导用户询问关于中国古籍的问题。
4. 连接到结束节点
```

## 8. 进阶技巧

### 8.1 使用变量存储器

**场景**：多轮对话中记住用户信息

```
第一轮：
用户：我叫张三
系统：
├─ 变量提取器：提取 name = "张三"
└─ 变量存储器：存储 name

第二轮：
用户：我想了解论语
系统：
├─ 变量存储器：取出 name = "张三"
└─ 大模型：张三您好，关于论语...
```

---

### 8.2 使用工作流节点

**场景**：复用已有工作流

```
主工作流：
├─ 判断用户意图
├─ 调用【工作流节点】→ 子工作流1（古籍问答）
└─ 调用【工作流节点】→ 子工作流2（诗词鉴赏）

优势：
✓ 模块化设计
✓ 便于维护
✓ 可复用
```

```
   ├─ 重试次数：2次
   └─ 异常处理方式：

```

## 9. 常见问题

### Q1：节点无法连接？
```
原因：节点输入输出类型不匹配
解决：使用代码节点转换类型
```

### Q2：知识库召回不准确？
```
解决：
1. 调整 Top K 和 Score 阈值
2. 优化文档分段
3. 使用知识库Pro节点
```

### Q3：大模型回答不符合预期？
```
解决：
1. 优化系统提示词
2. 提供更多示例
3. 使用更强的模型
```

### Q4：工作流执行缓慢？
```
解决：
1. 检查节点是否有不必要的等待
2. 并行处理独立节点
3. 使用更快的模型
```
