# 课程演示方案（简化版）

## 🎯 核心策略

**整体演示** → 讯飞星辰Agent（可视化）  
**拆解演示** → 通义千问 Qwen API（代码级）

## 🎓 课程流程设计

### 第一阶段：震撼开场（10分钟）

**使用：讯飞星辰Agent**

**演示内容**：
```
1. 登录星辰Agent平台
2. 展示已搭建好的"古籍问答助手"
3. 现场演示：
   ├─ 文字对话
   ├─ 语音对话（如果有虚拟人）
   └─ 知识库问答

4. 强调：
   "5分钟就能搭建这样的系统，
    但你不知道它怎么工作的！
    
    接下来，我们拆开黑盒，
    用代码实现同样的功能。"
```

---

### 第二阶段：原理拆解（40分钟）

**使用：通义千问 Qwen API + Python代码**

#### 步骤1：ASR语音识别（10分钟）

**演示脚本**：`demos/01_asr_demo.py`

```
讲师操作：
1. 打开通义千问控制台（投屏）
2. 展示如何获取API Key
3. 将Key粘贴到脚本
4. 运行脚本，展示识别结果

学员理解：
✓ ASR的核心参数（model, format, sample_rate）
✓ 如何调用API
✓ 如何解析结果
```

---

#### 步骤2：TTS语音合成（10分钟）

**演示脚本**：`demos/02_tts_demo.py`

```
讲师操作：
1. 使用同一个Key
2. 运行脚本，播放合成语音
3. 对比不同音色

学员理解：
✓ TTS的音色选择
✓ 如何生成音频文件
✓ 参数调整对效果的影响
```

---

#### 步骤3：知识库（10分钟）

**演示脚本**：`demos/03_kb_demo.py`

```
讲师操作：
1. 先展示硬编码方案（简单）
2. 再展示LLM方案（智能）
3. 对比两者差异

学员理解：
✓ 精确匹配 vs 模糊理解
✓ 硬编码 vs LLM的优劣
✓ 为什么需要知识库
```

---

#### 步骤4：整合演示（10分钟）

**演示脚本**：`demos/04_integration_demo.py`

```
讲师操作：
1. 运行整合脚本
2. 观察三个步骤依次执行：
   ASR → 知识库 → TTS
3. 强调：这就是核心逻辑

学员理解：
✓ 三个模块如何串联
✓ 数据如何流转
✓ 完整系统的本质
```

---

### 第三阶段：完整系统（15分钟）

**使用：Flask Web系统（基于Qwen API）**

**演示内容**：
```
1. 运行 start_demo.py
2. 打开 http://localhost:5000
3. 演示完整功能：
   ├─ 文字提问
   ├─ 语音提问
   ├─ 多音色切换
   └─ 对话记录

4. 对比星辰Agent：
   "看，我们用代码实现了同样的效果，
    而且完全可控、可定制！"
```

---

### 第四阶段：对比总结（10分钟）

**投屏展示对比表**：

| 维度 | 星辰Agent | Flask自研 | 适用场景 |
|------|----------|----------|---------|
| **开发速度** | ⭐⭐⭐⭐⭐ | ⭐⭐ | 快速验证 |
| **技术理解** | ⭐ | ⭐⭐⭐⭐⭐ | 学习技术 |
| **定制能力** | ⭐⭐ | ⭐⭐⭐⭐⭐ | 企业项目 |
| **虚拟形象** | ✅ | ❌ | 展示类应用 |
| **成本** | 订阅制 | 按量付费 | 看规模 |

**讨论**：什么场景用哪个？
