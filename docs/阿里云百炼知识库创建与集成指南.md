# 阿里云百炼平台知识库创建与Flask集成指南

## 📋 文档目标

本文档指导如何在阿里云百炼（Bailian）平台创建知识库，并提供API接口供Flask系统调用。

---

## 🌟 为什么用百炼平台的知识库？

### 优势对比

| 方案 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| **硬编码** | 简单直接 | 无法扩展 | 演示 |
| **百炼知识库** | 专业向量检索<br>Web界面管理<br>支持多种文档 | 需要网络<br>有成本 | 生产环境 ✅ |
| **自建向量库** | 完全自主 | 开发成本高 | 大规模应用 |

**推荐理由**：
- ✅ 专业的向量检索引擎
- ✅ 可视化管理界面
- ✅ 支持PDF、Word、Markdown等多种格式
- ✅ 自动分段、Embedding
- ✅ 提供REST API，易于集成

### 步骤3：编写知识库调用函数

**创建知识库模块**：`kb_client.py`

```python
# -*- coding: utf-8 -*-
"""
百炼知识库客户端
"""
import requests
from config import BAILIAN_API_KEY, BAILIAN_KB_ID, KB_TOP_K, KB_SCORE_THRESHOLD


class BailianKBClient:
    """百炼知识库客户端"""
    
    def __init__(self):
        self.api_key = BAILIAN_API_KEY
        self.kb_id = BAILIAN_KB_ID
        self.base_url = "https://dashscope.aliyuncs.com/api/v1/services/retrieval/knowledge-base"
    
    def search(self, query, top_k=KB_TOP_K, score_threshold=KB_SCORE_THRESHOLD):
        """
        检索知识库
        
        Args:
            query: 查询问题
            top_k: 返回结果数量
            score_threshold: 相似度阈值
        
        Returns:
            list: 检索结果列表
        """
        url = f"{self.base_url}/{self.kb_id}/retrieve"
        
        headers = {
            "Authorization": f"Bearer {self.api_key}",
            "Content-Type": "application/json"
        }
        
        data = {
            "query": query,
            "top_k": top_k,
            "score_threshold": score_threshold
        }
        
        try:
            response = requests.post(url, headers=headers, json=data, timeout=10)
            response.raise_for_status()
            
            result = response.json()
            
            # 解析结果
            if result.get('success'):
                return result.get('data', {}).get('records', [])
            else:
                print(f"知识库检索失败：{result.get('message')}")
                return []
        
        except Exception as e:
            print(f"知识库API调用异常：{str(e)}")
            return []
    
    def format_results(self, results):
        """
        格式化检索结果
        
        Args:
            results: 原始检索结果
        
        Returns:
            list: 格式化后的结果
        """
        formatted = []
        
        for item in results:
            formatted.append({
                'content': item.get('content', ''),
                'score': item.get('score', 0),
                'source': item.get('metadata', {}).get('file_name', '知识库'),
                'chunk_id': item.get('chunk_id', '')
            })
        
        return formatted


# 全局实例
kb_client = BailianKBClient()


def search_knowledge_base(query):
    """
    检索知识库（简化接口）
    
    Args:
        query: 查询问题
    
    Returns:
        list: 格式化后的结果
    """
    results = kb_client.search(query)
    return kb_client.format_results(results)


# 测试代码
if __name__ == "__main__":
    # 测试知识库检索
    test_query = "学而时习之是什么意思"
    results = search_knowledge_base(test_query)
    
    print(f"查询：{test_query}")
    print(f"找到 {len(results)} 条结果：\n")
    
    for i, result in enumerate(results, 1):
        print(f"结果 {i}:")
        print(f"  内容：{result['content'][:100]}...")
        print(f"  相似度：{result['score']:.4f}")
        print(f"  来源：{result['source']}")
        print()
```

### 步骤4：集成到Flask

**修改 app.py**：

```python
# -*- coding: utf-8 -*-
from flask import Flask, request, jsonify, render_template
from kb_client import search_knowledge_base
import dashscope
from config import QWEN_API_KEY

app = Flask(__name__)
dashscope.api_key = QWEN_API_KEY


@app.route('/')
def index():
    return render_template('index.html')


@app.route('/ask', methods=['POST'])
def ask():
    """处理问答请求"""
    
    data = request.json
    question = data.get('question', '')
    
    if not question:
        return jsonify({'error': '问题不能为空'}), 400
    
    try:
        # 1. 检索知识库
        kb_results = search_knowledge_base(question)
        
        if not kb_results:
            return jsonify({
                'answer': '抱歉，未找到相关内容。',
                'source': ''
            })
        
        # 2. 构建上下文
        context = "\n\n".join([r['content'] for r in kb_results[:3]])
        
        # 3. 调用LLM生成答案
        from dashscope import Generation
        
        prompt = f"""基于以下知识库内容回答问题：

知识库内容：
{context}

用户问题：{question}

请用通俗易懂的语言回答，控制在200字以内。"""
        
        response = Generation.call(
            model='qwen-turbo',
            prompt=prompt
        )
        
        answer = response.output.text
        source = kb_results[0]['source']
        
        # 4. 返回结果
        return jsonify({
            'answer': answer,
            'source': source,
            'kb_results_count': len(kb_results)
        })
    
    except Exception as e:
        return jsonify({'error': str(e)}), 500


if __name__ == '__main__':
    app.run(debug=True, port=5000)
```
