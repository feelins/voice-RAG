# 讯飞星辰Agent三步骤渐进式演示方案

## 🎯 教学策略

通过三个逐步优化的版本，让学员理解：
1. 基础版 → 能用，提取知识库内容
2. 优化版 → 加入AI理解，更智能
3. 完善版 → 加入逻辑控制，更完善

---

## 📋 三步骤概览

```
步骤1：基础版 - 知识库提取
├─ 节点：开始 → 知识库 → 代码 → 结束
├─ 特点：提取知识库内容，简单直接
└─ 用时：8分钟

步骤2：智能版 - 加入AI理解
├─ 节点：开始 → 知识库 → 大模型 → 结束
├─ 特点：回答自然、有解释
└─ 用时：10分钟

步骤3：完善版 - 加入智能决策
├─ 节点：开始 → 决策 → 知识库 → 大模型 → 代码 → 结束
├─ 特点：能识别意图、格式化输出
└─ 用时：15分钟
```

---

## 🔧 步骤1：基础版 - 知识库内容提取

### 目标
让学员理解知识库检索的基本原理，看到最简单的问答效果

### 工作流结构

```
┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
│ 开始节点 │ ──→ │ 知识库   │ ──→ │ 代码节点 │ ──→ │ 结束节点 │
│         │     │ 节点    │     │(提取内容)│     │         │
└─────────┘     └─────────┘     └─────────┘     └─────────┘
```

**重要说明**：
- ⚠️ **必须加代码节点**：因为知识库返回的是JSON数组，直接输出会让虚拟人读出所有JSON符号
- ✅ 代码节点的作用：从JSON中提取 `content` 字段

---

### 详细配置

#### 节点1：开始节点

**默认配置即可**：
```
配置：
└─ AGENT_USER_INPUT (String) - 用户本轮对话输入内容

示例：
用户输入："学而时习之是什么意思"
```

---

#### 节点2：知识库节点

**添加知识库**：
```
1. 拖拽【知识库】节点到画布
2. 点击【+ 添加知识库】
3. 选择：论语知识库
4. 点击【添加】
```

**配置参数**：
```
Top K：3（返回前3条结果）
Score阈值：0.7（匹配度>=70%才返回）
调用逻辑：强制调用
```

**配置输入**：
```
Query（查询内容）：
├─ 参数名：query
├─ 类型：String
└─ 变量值：引用 [开始节点.AGENT_USER_INPUT]
```

**输出**：
```
results (Array<Object>)
├─ content：检索到的文本内容
├─ score：匹配度分数（0-1）
├─ docId：文档ID
└─ 其他字段...
```

---

#### 节点3：代码节点（⚠️ 必需）

**为什么必须加代码节点？**
```
知识库返回的是JSON数组：
[
  {
    "content": "答案：「学而时习之」...",
    "score": 0.997,
    ...
  }
]

如果直接输出：
❌ 虚拟人会读："左中括号 左大括号 双引号 content..."
✅ 需要代码节点提取 content 字段
```

**配置输入**：
```
点击【+ 添加输入】

参数名：kb_results
类型：Array
变量值：引用 [知识库节点.results]
```

**编写代码**：
```python
# -*- coding: utf-8 -*-
def main(kb_results):
    """从知识库结果中提取content字段"""
    
    # 检查是否有结果
    if not kb_results or len(kb_results) == 0:
        return {
            "answer": "抱歉，未找到相关内容。"
        }
    
    # 提取第一条结果的content
    first_result = kb_results[0]
    content = first_result.get('content', '未找到内容')
    
    return {
        "answer": content
    }
```

**配置输出**：
```
输出参数：
├─ 参数名：answer
└─ 类型：String
```

---

#### 节点4：结束节点

**⚠️ 关键配置**：必须选择正确的回答模式！

**回答模式**：
```
○ 返回参数，由工作流生成        ← ❌ 不要选这个（会输出JSON）
● 返回设定格式配置的回答        ← ✅ 选这个！
```

**配置输出参数**：
```
输出参数：
├─ 参数名：answer
├─ 类型：String
└─ 变量值：引用 [代码节点.answer]
```

**配置回答内容**：
```
思考内容：
（留空）

回答内容：
{{answer}}
```

**⚠️ 常见错误**：
```
❌ 错误写法：
{"answer": "{{answer}}"}
或
answer: {{answer}}

✅ 正确写法：
{{answer}}
（只有这一行，没有其他任何字符）
```

### 存在的问题（讲师现场演示）

**问题1：回答是知识库的原文**
```

如果原文不通俗，用户理解困难
```

**问题2：无法灵活理解问题**
```

→ 无法根据用户需求调整表达方式
```

**问题3：无法综合多条信息**
```

无法综合多条信息给出更完整的答案
```

**引导学员思考**：
> "大家看，虽然找到了答案，但是：
> 1. 直接返回知识库原文，不够灵活
> 2. 无法根据用户需求调整表达
> 3. 无法综合多条信息
> 
> 怎么解决？→ 加入大模型！
> 
> 大模型可以：
> - 理解用户意图
> - 用通俗语言重新表达
> - 综合多条信息
> 
> 接下来看步骤2..."

## 🚀 步骤2：智能版 - 加入大模型理解

### 目标
让学员理解大模型的作用：将知识库内容"理解"后用自然语言表达

### 工作流结构

```
┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐     ┌─────────┐
│ 开始节点 │ ──→ │ 知识库   │ ──→ │ 大模型   │ ──→ │ 代码节点 │ ──→ │ 结束节点 │
│         │     │ 节点    │     │ 节点    │     │(可选)   │     │         │
└─────────┘     └─────────┘     └─────────┘     └─────────┘     └─────────┘
```

**关键变化**：
- ✅ 在知识库和代码节点之间插入大模型节点
- ✅ 大模型节点接收：用户问题 + 知识库结果
- ✅ 代码节点功能升级：从"提取content"变为"格式化+添加来源"
- ⚠️ 代码节点在步骤2可选（为了对比效果，建议先不加）

**演进逻辑**：
```
步骤1：知识库 → 代码（提取content）→ 结束
              ↓ 问题：直接输出原文，不够智能
              
步骤2：知识库 → 大模型（理解+表达）→ 结束
              ↓ 在知识库和结束之间插入大模型
```

**配置输入**：

**编写代码**：
```python
# -*- coding: utf-8 -*-
def main(kb_results, llm_answer):
    """
    格式化输出：添加来源信息和美化格式
    """
    
    # 提取来源信息
    sources = []
    if kb_results and isinstance(kb_results, list):
        for item in kb_results[:3]:
            if isinstance(item, dict):
                # 尝试获取fileName，如果没有就用docId
                source = item.get('fileName', '') or item.get('title', '') or '知识库'
                if source and source not in sources:
                    sources.append(source)
    
    # 格式化最终输出
    final_answer = llm_answer
    
    if sources:
        source_text = "、".join(sources)
        final_answer += f"\n\n━━━━━━━━━━━━━━━━━"
        final_answer += f"\n📚 来源：{source_text}"
        final_answer += f"\n💡 提示：以上内容来自古籍知识库"
    
    return {
        "answer": final_answer
    }
```

**配置输出**：

**配置输出参数**：
```
输出参数：
├─ 参数名：answer
├─ 类型：String
└─ 变量值：
    根据来源分支不同：
    - 古籍问答分支：引用 [代码节点.answer]
    - 闲聊分支：引用 [闲聊大模型.Output]
    - 默认分支：引用 [默认大模型.Output]
```

**⚠️ 注意**：
```
星辰Agent会自动处理多个分支汇入同一结束节点
只需要确保每个分支的输出参数名都是 answer 即可
```

**配置回答内容**：
```
回答内容：
{{answer}}
```
