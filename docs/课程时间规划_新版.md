# 课程时间规划（新版 - 2-2.5小时）

## 📊 课程总览

**课程时长**：2-2.5小时  
**学员人数**：10-15人  
**教学模式**：演示 + 讲解 + 实操  

---

## 🎯 课程目标

通过两个阶段，让学员：
1. ✅ 理解AI应用的快速搭建（星辰Agent）
2. ✅ 理解模块化开发思路（百炼平台）
3. ✅ 掌握Flask整合能力
4. ✅ 能够选择合适的技术方案

---

## 📋 课程结构

```
第一阶段：讯飞星辰Agent（30-45分钟）
├─ 三步骤渐进式演示
├─ 可视化工作流搭建
└─ 快速看到完整效果

第二阶段：阿里百炼平台（60-75分钟）
├─ 拆解三大模块
├─ Flask系统集成
└─ 学员实操环节

总计：90-120分钟（1.5-2小时）
预留缓冲：10-30分钟（答疑、突发情况）
```

### 详细安排

#### 00:00 - 00:05 | 开场介绍（5分钟）

**讲师操作**：
- 投屏展示课程大纲
- 说明两个阶段的关系

**讲解话术**：
```
"今天我们用2小时，带大家体验AI应用开发的两种思路：

第一阶段（30分钟）：
用讯飞星辰Agent，5分钟搭建一个虚拟人问答系统
- 看效果：快速体验AI能力
- 看局限：理解黑盒的问题

第二阶段（1小时）：
用阿里百炼平台，拆解模块，自己组装
- 理解原理：知识库、ASR、TTS、LLM
- 学会整合：用Flask把能力串起来

最后（30分钟）：
你们自己动手，组装属于自己的AI系统"
```


#### 00:15 - 00:25 | 步骤2：智能版（10分钟）

```
工作流：开始 → 知识库 → 大模型 → 结束

```

```
步骤1：知识库原文

看，大模型的作用就是：
✓ 理解内容
✓ 灵活表达
✓ 通俗易懂

✗ 不能识别闲聊
✗ 没有来源信息
```

**演示内容**：创建和使用知识库

**时间安排**：
```
平台演示：8分钟
├─ 登录百炼平台（1分钟）
├─ 创建知识库（2分钟）
├─ 上传文档（提前准备好）（2分钟）

代码演示：5分钟

├─ 运行测试代码（1分钟）
├─ 讲解返回结果（2分钟）

├─ 硬编码 vs 知识库（1分钟）
```

**讲解要点**：
```
"星辰Agent的知识库是黑盒，
 现在我们用百炼平台：

✓ 怎么检索

"
```

---

#### 00:55 - 01:10 | 模块2：ASR + TTS（15分钟）

**演示内容**：语音识别和合成

**时间安排**：
```
ASR演示：7分钟
├─ 打开 01_asr_demo.py（1分钟）
├─ 讲解核心代码（3分钟）
├─ 运行测试（2分钟）
├─ 讲解参数调整（1分钟）

TTS演示：7分钟
├─ 打开 02_tts_demo.py（1分钟）
├─ 讲解核心代码（3分钟）
├─ 运行测试（2分钟）
├─ 对比不同音色（1分钟）

小结：1分钟
```

**讲解要点**：
```
"ASR和TTS看起来复杂，
 其实就是API调用：

ASR：
- 输入：音频文件
- 输出：文字

TTS：
- 输入：文字
- 输出：音频文件

关键参数：
- ASR：model, format, sample_rate
- TTS：voice, format, volume

星辰Agent帮你封装了，
但现在你知道底层怎么用了！"
```

#### 01:10 - 01:30 | 模块3：Flask整合（20分钟）

**演示内容**：完整系统演示

**时间安排**：
```

├─ 讲解核心函数（4分钟）
│   ├─ ASR调用
│   ├─ 知识库检索
```

```
"现在你们看到：

星辰Agent做的事情：

Flask做的事情：
ASR → 知识库 → LLM → TTS

本质上是一样的！

区别：
- 星辰：拖拽配置，快速

你学会了原理，
两种方式都能用！"
```

## 📝 应急预案

### 常见情况处理

**情况1：网络故障**
```
应对：
1. 使用离线演示视频
2. 提供完整代码U盘
3. 学员本地运行
```

**情况2：学员进度差异大**
```
应对：
1. 快的学员：做进阶任务
2. 慢的学员：讲师一对一指导
3. 准备不同难度的任务
```

**情况3：提问过多**
```
应对：
1. 现场问题：快速回答
2. 深入问题：记录下来，课后答疑群讨论
3. 控制单个问题时间（<3分钟）
```

**情况4：设备故障**
```
应对：
1. 准备备用笔记本
2. 准备投屏线缆
3. 手机热点备用
```
