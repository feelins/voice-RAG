## 📝 使用说明

### 语音提问
1. 点击"🎤 语音提问"按钮
2. 浏览器会请求麦克风权限（首次使用）
3. 按钮变红，开始录音
4. 说话后再次点击停止录音
5. 系统会自动识别并回答

### 文字提问
1. 在文本框输入问题
2. 点击"📝 文字提问"
3. 或按 `Ctrl + Enter` 快捷键

### 示例问题
- 学而时习之是什么意思？
- 孔子的弟子有谁？
- 什么是仁？
- 诗经中有哪些著名篇目？
- 红楼梦第五回讲什么？（测试拒答）

## 🔧 技术细节

### 后端（Flask）
```python
主要路由：
- /                        # 首页
- /ask                     # 文字问答
- /voice_ask               # 语音问答（模拟识别）
- /audio/<filename>        # 音频文件服务
```

### 前端（JavaScript）
```javascript
核心功能：
- 录音功能（MediaRecorder API）
- 音频播放（HTML5 Audio）
- 异步请求（Fetch API）
```

### 音频文件
- **格式**：MP3
- **编码**：fltp
- **采样率**：32,000 Hz
- **声道**：单声道
- **时长**：38.4 秒
- **大小**：602 KB

## 🐛 问题排查

### 无法录音
- 检查浏览器是否支持 MediaRecorder API
- 检查麦克风权限是否授权
- 尝试使用 Chrome 或 Edge 浏览器

### 音频无法播放
- 检查控制台错误信息（F12）
- 检查 `static/audio/minimax_tts.mp3` 是否存在
- 尝试直接访问 `http://localhost:5000/audio/minimax_tts.mp3`

### 应用无法启动
- 检查 Python 版本（需要 3.7+）
- 检查 Flask 是否安装：`pip install flask`
- 检查端口 5000 是否被占用
